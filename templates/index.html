The College Project Problem

In academic institutions, students typically form project teams based on friendship rather than skill compatibility:

  • Redundant teams where everyone knows Python but nobody knows Frontend or Database.
  • Scattered student capabilities with no central visibility for faculty mentors.
  • Frustration during grading due to severe skill gaps and project incompletion.

The SkillGraph Solution

SkillGraph models students and project demands as a mathematical network to solve team composition:

  • Transparent rule-based Python heuristic matching that maximizes skill coverage.
  • Prioritizes complementary skills rather than duplicated proficiencies.
  • Backed by a normalized SQLite relational database with strict DBMS constraints.

Technology Architecture

Python Flask

RESTful APIs, request routing, session switching, and recommendation engine execution.

SQLite & Relational SQL

7 normalized tables, explicit foreign keys (`ON DELETE CASCADE`), and multi-table `JOIN` queries.

NetworkX

Graph theory modeling: student-skill-project nodes, weighted edges, and degree centrality.

Vis.js & Chart.js

Interactive force-directed graph canvas and real-time faculty analytical distribution charts.
